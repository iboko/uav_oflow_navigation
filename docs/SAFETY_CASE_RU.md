# Safety case для режима полета БВС по оптическому потоку

## 1. Основной риск

Оптический поток не измеряет абсолютное положение. Он оценивает движение относительно подстилающей поверхности. При плохой текстуре, воде, стекле, снегу, дыме, пыли, вибрациях, чрезмерной высоте или потере дальномера канал ОП может дать ошибочную скорость.

## 2. Запрет включения режима

Режим ОП запрещается включать при следующих условиях:

```text
IMU invalid
rangefinder invalid
height < min_height
height > max_height
abs(roll) > max_tilt
abs(pitch) > max_tilt
optical_flow_quality < min_quality
flow timestamp stale
range timestamp stale
```

## 3. Деградация

Переход в `DEGRADED_HOLD` выполняется при:

```text
низком качестве ОП;
просроченном ОП-сообщении;
отклонении инновации EKF;
некорректной скорости ОП;
резком скачке потока.
```

В этом состоянии САУ не должна усиливать горизонтальные команды по ОП. Разрешенные действия зависят от автопилота и программы испытаний: торможение, зависание по резервному источнику, посадка или ручной режим.

## 4. Критичный отказ

Переход в `FAILSAFE_LAND` выполняется при:

```text
потере IMU;
потере дальномера;
выходе высоты за допустимые пределы;
чрезмерном крене/тангаже;
невозможности подтвердить высоту над поверхностью.
```

## 5. Летные ограничения первого этапа

```text
высота: 0.5...1.5 м;
горизонтальная скорость: не более 0.5 м/с;
углы крена/тангажа: не более 5...8 градусов;
зона: текстурированная поверхность, сетка/ковер/маркерное поле;
винты: сняты на стендовой проверке;
пилот: внешний пилот с ручным перехватом;
ГНСС: не отключать физически на первых проверках, а переводить EKF-режим по программе испытаний.
```

## 6. Приемочные критерии RTOS-ядра

```text
C++ core собирается без предупреждений;
unit-тесты проходят;
нет динамической аллокации в рабочем цикле;
проверены знаки осей ОП;
проверен рычаг установки датчика;
проверен innovation gate;
проверена реакция на потерю дальномера;
проверена реакция на низкое качество ОП;
все отказные причины имеют диагностический код.
```
