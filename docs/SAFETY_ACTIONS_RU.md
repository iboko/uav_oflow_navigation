# Реакция на отказы навигации: действия безопасности

## Что было

Автомат `SafetyMonitor` выдавал режимы `FLOW_NAV`, `DEGRADED_HOLD`,
`FAILSAFE_LAND`, `MANUAL_REQUIRED`, но никакой реакции не следовало:
модуль PX4 только публиковал диагностику. Одиночный сбойный отсчет
и длительная потеря навигации не различались.

## Что сделано

`ofnav::SafetyActionManager` (`firmware/rtos_core`) — детерминированное
отображение режима навигации в запрашиваемое действие:

| Действие | Условие | Снятие |
|---|---|---|
| `ALTITUDE_HOLD` | `DEGRADED_HOLD`/`FAILSAFE_LAND` дольше 0,3 с | 1 с непрерывного `FLOW_NAV` |
| `LAND` | `FAILSAFE_LAND` дольше 0,2 с; деградация без восстановления дольше 5 с; обратный ход часов | только `reset()` |
| `MANUAL_TAKEOVER` | `MANUAL_REQUIRED` | только `reset()` |
| `NONE` | исправная навигация | — |

Свойства:

- подтверждение по времени отсекает кратковременные сбои;
- перемежающаяся деградация (без 1 с восстановления) копится и
  эскалирует до посадки;
- посадка и передача управления фиксируются;
- менеджер **никогда** не требует возврата в режим удержания положения:
  после восстановления действие становится `NONE`, дальнейшее —
  решение пилота;
- **только в воздухе**: на земле (`vehicle_land_detected.landed`,
  неармированный аппарат или отсутствие данных о посадке) менеджер
  сбрасывается и выдает `ON_GROUND`, кроме уже зафиксированной посадки;
- **только после установившейся навигации** (`require_engagement`):
  действия возможны, когда `FLOW_NAV` в полете продержался 1 с; до
  этого — `NOT_ENGAGED`. Иначе взлет с высоты ниже диапазона датчика
  (0,2 м) сам по себе вызывал `ALTITUDE_HOLD`, а затем `LAND`;
- при армировании менеджер сбрасывается: предполетные состояния не
  переносятся в полет.

### PX4

Решение публикуется всегда (`debug_vect` `OFNAV_A`: действие, режим,
число отправленных команд) и показывается в `ofnav status`.
Команды автопилоту — **только** с флагом `-a` и **только** в армированном
состоянии, один раз на каждое новое действие:

| Действие | `vehicle_command` |
|---|---|
| `ALTITUDE_HOLD` | `DO_SET_MODE`, `PX4_CUSTOM_MAIN_MODE_ALTCTL` |
| `MANUAL_TAKEOVER` | `DO_SET_MODE`, `PX4_CUSTOM_MAIN_MODE_STABILIZED` |
| `LAND` | `NAV_LAND` на месте |

```sh
ofnav start -p camera -a   # только SITL / стенд со снятыми винтами
ofnav status               # safety action=... reason=... sent=N
listener debug_vect        # OFNAV_A
```

Исполнительные органы модуль по-прежнему не трогает.

## Проверка

- `test_ofnav`: подавление 100 мс сбоя, фиксированная посадка,
  гистерезис восстановления, эскалация перемежающейся деградации,
  `MANUAL_TAKEOVER`, обратный ход часов;
- PX4 SITL smoke-тест: модуль стартует с `-a`, в неармированном
  состоянии отправлено 0 команд.

Замкнутый контур в PX4 SITL + Gazebo (армирование, взлет, отказы
ОП и дальномера, выход из диапазона высоты) —
`docs/GAZEBO_FAILURE_SCENARIOS_RU.md`.

## Ограничения

Пороги времени — проектные значения; отказ ИИМ в замкнутом контуре
не проверялся; на реальном аппарате (стенд без винтов) не проверено.
