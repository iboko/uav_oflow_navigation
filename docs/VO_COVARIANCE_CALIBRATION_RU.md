# Эмпирическая калибровка ковариации скорости VO

## Что было

`velocity_uncertainty.py` строит ковариацию скорости по **заданным**
погрешностям (пиксели, высота, время, курс, фокус, плечо). Проверки
по независимому эталону не было; ковариация подавалась в РФК как есть.

## Что сделано

`src/velocity_covariance_calibration.py`:

```text
e_k = v_VO,k − v_ref,k,   C_cal,k = s · C_model,k + Q_floor
s = (1/F) Σ_f mean_k(NEES_f,k)/2   (MLE скаляра, полеты с равным весом)
b = среднее смещение по полетам настройки
```

- настройка и проверка — **разные** полеты (пересечение запрещено);
- проверка: средняя NEES (полоса 1,4…2,8 при ожидании 2) и доля NEES
  в пределах χ²(2, 95 %); нижняя граница доли — биномиальный допуск
  3σ около 0,95 для фактического числа отсчетов (не ниже 0,85);
- результат `consistent_on_holdout`; стенд отказывается работать с
  калибровкой, не подтвержденной на отложенных полетах.

Для реальных данных — командная строка:

```bash
python -m src.velocity_covariance_calibration \
  --fit f1:vo_f1.csv:ref_f1.csv f2:... f3:... \
  --holdout h1:vo_h1.csv:ref_h1.csv h2:... \
  --output vo_covariance_calibration.json
```

`vo_*.csv`: `timestamp_us, accepted, vn_m_s, ve_m_s, cov_nn, cov_ne, cov_ee`;
`ref_*.csv`: `timestamp_us, vn_m_s, ve_m_s` (RTK-ГНСС, система захвата
движения); сопоставление по ближайшей метке (`--max-time-offset-us`).

## Результат на синтетическом стенде

Скорость VO в осях корпуса, 3 полета настройки, 2 проверки:

| Величина | Значение |
|---|---|
| масштаб s | 0,0029 |
| средняя NEES на проверке | 1,94 (ожидается 2) |
| доля в χ²(2, 95 %) | 0,96 |

Модельная ковариация на идеальных изображениях оказалась в ~350 раз
консервативнее фактической (заданные 0,55 пикс. и 0,12 м/с минимума
против ≈0,02 м/с фактической ошибки). Калиброванная ковариация
используется стендом в РФК.

## Ограничения

Синтетические изображения без шумов матрицы, смаза и рельефа;
скалярный масштаб не моделирует зависимость от текстуры, высоты и
скорости отдельно. Для полета требуется калибровка на реальных данных.
