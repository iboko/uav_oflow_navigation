# Оценка движения по нижней камере: исследовательский модуль

**Статус:** офлайн-алгоритм для отработки на данных НИИВК. Не является
законченной визуальной одометрией (VO), визуально-инерциальной одометрией
(VIO), системой удержания положения или бортовым источником для EKF2.

## Назначение

Файл `src/ground_visual_motion.py` вычисляет **горизонтальную скорость
нижней камеры относительно неподвижной поверхности** при допущении
локально плоской земли и малого крена/тангажа:

1. Выделение характерных точек по Ши–Томаси в первом кадре.
2. Сопровождение точек методом Лукаса–Канаде между кадрами.
3. Проверка согласованности прямого/обратного сопровождения.
4. Оценка движения сцены частично-аффинной моделью с RANSAC.
5. Определение смещения в главной точке изображения; исключение
   вращательной составляющей вокруг оптической оси в приближении плоскости.
6. Приведение смещения в метры по фокусному расстоянию (в пикселях),
   времени между кадрами и **высоте над поверхностью**.
7. Переход из осей изображения в оси корпуса по **предварительно
   определенной** матрице установки камеры.

Для близкого к надиру положения и плоской поверхности:

```text
d = A * [cx, cy] + t - [cx, cy]      # движение изображения в главной точке
v_image_x = -h * d_x / (fx * dt)
v_image_y = -h * d_y / (fy * dt)
v_body_xy = R_body_image_2d * v_image_xy
```

Эта модель не предназначена для автоматического применения при
значительных наклонах, неровном рельефе и существенной перспективной
деформации. Результат не содержит абсолютных координат и не компенсирует
дрейф без внешней привязки.

## Запуск (первичная программная проверка)

```bash
python -m pip install -e '.[dev,vision]'
python -m pytest -q tests/test_ground_visual_motion.py
```

Использование на паре серых кадров `uint8`:

```python
from src.ground_visual_motion import CameraCalibration, estimate_ground_motion

calib = CameraCalibration(
    focal_x_px=1400, focal_y_px=1400,
    center_x_px=320, center_y_px=240,
    image_to_body_xy=((1.0, 0.0), (0.0, 1.0)),
)
result = estimate_ground_motion(
    first_gray, second_gray, dt_s=0.1, height_agl_m=100,
    calibration=calib, roll_rad=0.0, pitch_rad=0.0,
)
```

Матрица единичной ориентации приведена **только для условного численного
примера**. Для БВС фактическое преобразование осей и знаков должно быть
определено по монтажной документации и проверено на стенде НИИВК.

## Что предоставить НИИВК для перехода к полетному ПО

- Записи кадров с исходными временными метками экспозиции и параметрами
  внутренней калибровки камеры, разрешением, частотой, типом затвора.
- Расстояние до подстилающей поверхности и его точность, отдельно от
  барометрической высоты; сведения о рельефе местности.
- Инерциальные измерения и ориентация БВС с синхронизацией относительно
  камеры; координаты камеры относительно центра масс.
- Эталонная траектория из независимого источника на этапе испытаний,
  не используемая оценивающим алгоритмом как подсказка.
- Реальные данные с различных высот, включая 20, 50 и 100 м, с
  разной текстурой/освещенностью и потерями кадров.

## Оставшиеся математические и инженерные задачи

1. Строгая оценка матрицы ошибок измерений по реальным логам;
   контроль числа, распределения и согласованности характерных точек.
2. Согласование времени изображений, высоты и ИИМ; компенсация
   движения и углов камеры на интервале экспозиции.
3. Полная проективная модель камеры и рельефа вместо плоского
   приближения; моделирование дисторсии и экструзии камеры.
4. Проверка наблюдаемости горизонтального смещения при длительном
   зависании и малых межкадровых сдвигах на высоте 100 м.
5. Реализация VO/VIO с учетом ковариаций и задержанных измерений,
   коррекция накопленного дрейфа по ортофотоплану (отдельные этапы).
6. Протокол испытаний: ошибки скорости и смещения, выбросы, доля
   отклоненных кадров, отказы, повторяемость результатов.

**Запрет:** передавать результат исследовательского модуля в контур
управления БВС до выполнения указанных проверок и аппаратной адаптации.
