# Профили источника скорости: датчик ОП и нижняя камера (0,2–120 м)

## Проблема

Ранее C++-ядро имело единственный допуск по высоте 0,2–4 м,
рассчитанный на миниатюрный датчик оптического потока. Измерения
камерной визуальной одометрии (VO) на 100 м всегда отклонялись
с причиной `HEIGHT_TOO_HIGH`, а ковариация скорости рассчитывалась
эмпирической формулой, ограниченной 0,35 м/с независимо от высоты.

## Реализация

`firmware/rtos_core/include/ofnav/ofnav.hpp`:

- `enum class SensorProfile { OpticalFlowSensor, DownwardCameraVo }`;
- `makeProfileConfig(profile, min_quality)` — единственный источник
  допусков для модуля PX4 и для SITL-replay;
- `flowVelocitySigma(cfg, h, |v|, quality)` — СКО скорости;
- новая причина отказа `VELOCITY_UNCERTAINTY`
  (код 14, прежние коды не изменены).

| Параметр | Датчик ОП | Камера VO |
|---|---|---|
| Высота, м | 0,2–4 | 5–120 |
| Макс. наклон, рад | 0,45 | 0,35 |
| Макс. скорость, м/с | 1,5 | 8 |
| Интервал интегрирования, с | ≤ 0,2 | ≤ 0,5 |
| Модель СКО | прежняя эмпирическая, ≤ 0,35 м/с | физическая |
| Порог СКО, м/с | — | 0,5 |

Физическая модель для камеры:

```text
σv² = σmin² + (h·σω)² + (|v|·σh,rel)²,   σω = 1,5 мрад/с, σh,rel = 1 %
```

`σω` соответствует ≈0,3 пикс. погрешности оцененного смещения при
f = 1000 пикс. и интервале 0,2 с. На 100 м σv ≈ 0,16 м/с.
Измерение отклоняется не по фиксированной «запрещенной» высоте,
а когда расчетная СКО превышает допустимую (`VELOCITY_UNCERTAINTY`).
Та же СКО используется как R в коррекции горизонтального РФК.

## PX4

- `ofnav start -p flow|camera` (по умолчанию `flow`, прежнее поведение);
- `ofnav status` печатает активный профиль;
- `ofnav sitl-replay <csv> [flow|camera]`.

Smoke-тест SITL (`tools/run_px4_sitl_replay_smoke.sh`) теперь выполняет
**оба** профиля на одних и тех же синтетических данных 100 м:

1. `flow` — все кадры отклонены по высоте (прежняя проверка безопасности);
2. `camera` — кадры приняты, отказов по высоте нет.

## Проверка

`test_ofnav`: отказ датчика ОП на 100 м, прием камеры на 100 м с точным
значением σv, рост σv с высотой, отказ по `VELOCITY_UNCERTAINTY`
при ужесточенном пороге, `HEIGHT_TOO_LOW` ниже 5 м, использование σv
оценивателя в РФК.

## Ограничения

σω и σh,rel — проектные допущения, а не результат метрологической
калибровки камеры. Экспериментальная проверка точности на 100 м
не выполнена. Профиль `camera` по-прежнему не передает данные в EKF2.

## Следующий этап

Определить σω и σh,rel по летным записям НИИВК с независимым эталоном
(методика `docs/VO_COVARIANCE_CALIBRATION_RU.md`), записать их в параметры
PX4 (`OFNAV_*`) вместо констант профиля и подтвердить допуск по высоте
на стенде HIL с реальной камерой.
