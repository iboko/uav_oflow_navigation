# Матрица фактической реализации UAV Optical Flow Navigation

Обновлено 18 октября 2026 г. по ветке `main`, коммиту `572fc45c335421ac9dcd87f9e964c60b2e694c0e` (с учетом объединенных PR №27–41, включая научную проверку в №39, видео в №40 и анализ поля в №41). Сохранены номера и названия 24 компонентов прежней матрицы.

Статус «реализовано» означает наличие работающего кода в указанном контуре. SITL — программное моделирование PX4/Gazebo; HIL — замкнутая проверка с физическим контроллером. Офлайн-обработка реальных записей не является полетом под управлением системы. Числа полетных испытаний взяты из отчетов репозитория; в ходе этого обновления сценарии заново не запускались.

## Последние результаты моделирования

Все результаты ниже — SITL в трехмерной сцене на 50 м. Калибровка поля B использует места из района испытаний, но не сами испытательные полеты: независимость есть по полетам, не по территории. В постановке A район испытаний исключен из калибровки; шесть исходных полетов A/B прошли все 5 проверок, но это не подтверждает надежную экстраполяцию на любой новый район.

| Маршрут, последняя серия поля B | Max / средняя ошибка маршрута | Сдвиг карты 3 м | Уход за 20 с отказа |
|---|---|---|---|
| box | 1,28 / 0,65 м | 39 из 39 отклонены | 0,13 м |
| diag | 1,60 / 0,64 м | 39 из 39 отклонены | 0,14 м |
| box_rf | 1,11 / 0,58 м | 39 из 39 отклонены | 0,10 м |

Все 5 проверок пройдены в трех новых полетах: захват карты, работа без ГНСС, ошибка маршрута, отказ карты, посадка. Предел ошибки маршрута — 2,18 м; ухода при отказе — 0,5 м. Всего с полем B описано 9 испытательных полетов, из них 3 с новой процедурой проверки отказа.

Исторический результат повтора diag (уход 0,61 м) остается непройденным. По разбору ULog отказ включался во время торможения. Перед новой серией добавили ожидание скорости ниже 0,1 м/с в течение 3 с и измерение ухода по средним положениям за 2 с; порог 0,5 м не меняли. Тайм-аут ожидания — 30 с, после него сбой все равно начинается, а результат ожидания записывается в отчет. Эти критерии относятся к испытательному стенду и используют истину симулятора, не являются входами навигации.
