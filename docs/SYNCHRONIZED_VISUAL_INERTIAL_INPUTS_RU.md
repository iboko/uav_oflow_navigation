# Согласование видеоданных, ориентации и погрешностей БВС

**Статус:** исследовательская обработка записей НИИВК, этап 4 (подготовка
к переходу на VIO). **Это не полноценная визуально-инерциальная
одометрия**: используются уже вычисленные кватернионы ориентации
ИНС/автопилота, а не совместный фильтр по сырым измерениям ИИМ и камере.

## Временные шкалы и отказные условия

Модуль `src/attitude_time_alignment.py` интерполирует кватернионы
бортовой ориентации к времени **середины экспозиции** кадра сферической
интерполяцией SLERP. Отсчеты должны иметь единую синхронизированную
шкалу времени; произвольные часы без известного смещения не допускаются.

Принята договоренность:

```text
t_ориентации = t_камеры + camera_to_attitude_offset_us
```

Смещение определяется стендовой калибровкой и передается явно.
Экстраполяция за границы журнала ориентации, нарушение порядка
временных меток и интервал между соседними оценками свыше допуска
приводят к отказу `ATTITUDE_SYNC_FAILED`, а не к использованию
последней доступной ориентации.

Журнал ориентации `attitude.csv`:

```csv
timestamp_us,qw,qx,qy,qz
1000000,1,0,0,0
1010000,0.999999,0,0,0.001414
1020000,0.999996,0,0,0.002828
```

**Кватернион задает поворот от связанной СК БВС FRD к навигационной
СК NED**, порядок компонент `[qw,qx,qy,qz]`, единичная норма.
Данные ориентации ИИМ и записи камеры не должны иметь скрытых
различий по направлению осей и отметке времени.

Пример обработки:

```bash
python -m src.run_camera_odometry \
  --manifest data/frames.csv \
  --calibration data/camera.yaml \
  --attitude-log data/attitude.csv \
  --camera-to-attitude-offset-us 5000 \
  --max-attitude-gap-us 25000 \
  --output-dir outputs/camera_sync
```

При `--attitude-log` столбцы крена, тангажа и курса в `frames.csv`
необязательны. При отсутствии журнала ориентации старые столбцы
`roll_rad,pitch_rad,yaw_rad` обязательны.

## Плечо установки камеры

В `camera.yaml` дополнительно допускается:

```yaml
# Только условный пример расположения камеры, все размеры в метрах.
image_to_body_xy: [[0, -1], [1, 0]]
body_from_camera: [[0, -1, 0], [1, 0, 0], [0, 0, 1]]
camera_offset_body_m: [0.10, 0.00, 0.08]
```

Плечо `camera_offset_body_m` — вектор **из центра масс БВС к
оптическому центру камеры** в связанной СК БВС (м).
При вращении камеры относительно центра масс ее оптический центр
перемещается даже при нулевом поступательном движении БВС.

Векторное соотношение для двух моментов наблюдения:

```text
p_камера^N = p_центр^N + R_nb r_камера^B

delta_p_центр^N =
    R_nb_prev delta_p_камера^Bprev -
    (R_nb_curr - R_nb_prev) r_камера^B
```

Поправка на плечо включается **только с подтвержденной трехмерной
калибровкой установки**. Без нее при ненулевом плече программа
останавливает обработку. Текущая модель оценивает только горизонтальное
перемещение над почти плоской поверхностью, не восстановление
полной пространственной траектории.

## Расчетная неопределенность горизонтальной скорости

По умолчанию ковариации не определяются: CSV содержит пустые
(нечисловые) значения, отчет — `NOT_ESTIMATED`.

Для исследовательских расчетов можно задать
`velocity_error_assumptions` в YAML. Ниже значения исключительно для
демонстрации структуры; это **не измеренные погрешности изделий НИИВК**:

```yaml
velocity_error_assumptions:
  fitted_displacement_sigma_px: 0.7
  height_sigma_m: 0.2
  interval_sigma_s: 0.001
  yaw_sigma_rad: 0.005
  focal_relative_sigma: 0.005
  camera_offset_sigma_m: 0.03
  velocity_model_floor_m_s: 0.01
```

Модель `src/velocity_uncertainty.py` использует линейное
распространение указанных ошибок по якобианам преобразований:
вклады смещения изображения, высоты, интервала наблюдения, курса,
фокусного расстояния, плеча установки и нижнего уровня ошибок.
Выход — симметричная положительно определенная матрица
ковариаций `(VN, VE)` с элементами
`velocity_cov_nn_m2_s2`, `velocity_cov_ne_m2_s2`,
`velocity_cov_ee_m2_s2`.

**Предупреждение:** расчет исходит из независимых погрешностей и
линейного приближения, не учитывает временные корреляции, погрешности
рельефа, искажения скользящего затвора и некорректную калибровку.
Без сопоставления нормированных инноваций с независимыми эталонными
данными нельзя называть эту матрицу статистически подтвержденной или
передавать ее в EKF2 для доверительного слияния.

## Протокол проверки НИИВК

Нужны кадры с исходным временем экспозиции, журнал кватернионов
ориентации с измеренным смещением временных шкал, измерения
расстояния до поверхности, документированная установка камеры
и независимая эталонная траектория. Испытания проводят
с различными поверхностями и высотами 20, 50, 100 м;
раздельно регистрируют ошибки, периодичность выбросов,
потери ориентации, задержки, изменение освещения и дрейф.

Следующий этап: временная интеграция **сырых** измерений ИИМ с
оценкой смещений нуля гироскопов, слияние с визуальными наблюдениями,
полноценная пространственная визуально-инерциальная одометрия
и коррекция накопленной ошибки по ортофотоплану.
