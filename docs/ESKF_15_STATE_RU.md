# Пятнадцатимерный фильтр ошибок инерциального состояния БВС

**Статус:** программно-математический офлайн-прототип, развитие
предыдущей обработки ОП, VO и ИИМ. Не предназначен для передачи
оценок в контур управления PX4 и не подтверждает зависание БВС без
ГНСС на высоте 100 м.

## Математическая постановка

Используются связанная система координат БВС **FRD** (вперед,
вправо, вниз) и навигационная **NED** (север, восток, вниз).

Номинальное состояние:

```text
p_n = (N,E,D)                   положение относительно произвольного начала, м
v_n = (VN,VE,VD)                скорость, м/с
q_nb = (qw,qx,qy,qz)            поворот FRD -> NED
b_g = (bgx,bgy,bgz)             смещение нуля гироскопов, рад/с
b_a = (bax,bay,baz)             смещение нуля акселерометров, м/с²
```

Вектор малых ошибок из **15 компонентов**:

```text
δx = [δp(3), δv(3), δθ(3), δbg(3), δba(3)]^T
R_true = R_nom Exp([δθ]x)     правая ошибка ориентации в FRD
```

Инерциальная модель (среднеточечная дискретизация):

```text
ω = ω_изм - b_g
f = f_изм - b_a
q(t+dt) = q(t) ⊗ Exp_q(ω_mid dt)
a_n = R_nb(q_mid) f_mid + (0,0,g)
v(t+dt) = v(t) + a_n dt
p(t+dt) = p(t) + v(t)dt + 0.5 a_n dt²
```

Для номинальной динамики матрица непрерывной линеаризации F
содержит блоки:

```text
F[p,v]  = I3
F[v,θ]  = -R_nb [f]x
F[v,ba] = -R_nb
F[θ,θ]  = -[ω]x
F[θ,bg] = -I3
```

Остальные блоки нулевые. Переход `Phi ≈ exp(F dt)` вычисляется
рядом до четвертого порядка на шаге до 0,05 с.

Матрица шумов процесса `Qd` получается интегрированием
`Phi(τ)G Qc G^T Phi(τ)^T` трехточечной квадратурой Гаусса.
Учитываются независимые белые шумы гироскопов, акселерометров
и случайные блуждания их смещений нуля. Временная корреляция,
нестационарные ошибки и неучтенная вибрация отсутствуют в модели;
реальную спектральную плотность необходимо оценивать по данным
изделия ИИМ.

## Коррекция по визуальным измерениям

Используется горизонтальная скорость **центра масс**, полученная
после обработки ОП/камеры, коррекции вращения и плеча установки:

```text
z = [VN_vision, VE_vision]^T
h(x) = [v_N, v_E]^T
H[:,3:5] = I2
ν = z - h(x)
S = H P H^T + R_visual
NIS = ν^T S^-1 ν
```

Коррекция разрешается только при положительно определенной
`R_visual`, согласованном времени и прохождении проверки
нормированной инновации. В программе задан начальный
порог `NIS=9,21034`, соответствующий 99-му процентилю
распределения хи-квадрат с двумя степенями свободы **только при
верной гауссовой модели ошибок**.

Обновление ковариации по форме Джозефа:

```text
P+ = (I-KH)P-(I-KH)^T + K R_visual K^T
```

После применения поправки к номинальному кватерниону выполняется
преобразование ковариации с якобианом сброса ошибки ориентации.

**Ограничение наблюдаемости:** два компонента визуальной скорости
не обеспечивают самостоятельного измерения абсолютного положения,
курса, высоты и всех смещений нуля ИИМ. При неподвижном БВС,
малых ускорениях и постоянной текстуре отдельные состояния
ненаблюдаемы или слабо наблюдаемы. Матрица 15×15 не является
доказательством наблюдаемости полной системы. Требуются анализ
линеаризованной наблюдаемости на заданной траектории и натурные
испытания.

## Запуск на журнале НИИВК

Для автономной проверки реализован:
`src/run_eskf_offline.py`, который принимает журналы сырых
измерений ИИМ и результатов визуальной одометрии предыдущих этапов.

```bash
python -m pip install -e '.[dev,vision]'
python -m src.run_eskf_offline \
  --imu-log data/imu.csv \
  --visual-log outputs/camera_sync/visual_odometry.csv \
  --config data/eskf_noise.yaml \
  --output-dir outputs/eskf
```

Пример `eskf_noise.yaml` (числа только для проверки ПО, не являются
фактическими характеристиками ИИМ НИИВК):

```yaml
stationary_calibration_confirmed: true
initial_quaternion_body_to_ned: [1, 0, 0, 0]
gyro_bias_body_rad_s: [0, 0, 0]
accel_bias_body_m_s2: [0, 0, 0]
gyro_rad_s_sqrt_hz: 0.003
accel_m_s2_sqrt_hz: 0.03
gyro_bias_walk_rad_s2_sqrt_hz: 0.00005
accel_bias_walk_m_s3_sqrt_hz: 0.0003
max_imu_dt_s: 0.05
visual_to_imu_offset_us: 0
allow_experimental_visual_covariance: true
```

Если ковариация получена и проверена на независимых реальных
данных, можно указать `visual_covariance_validated: true`
вместо экспериментального разрешения. Программа не может
самостоятельно подтверждать истинность этого заявления.
Одновременно включать оба режима запрещено.

Часы камеры и ИИМ должны иметь измеренное смещение:
`t_имм = t_камеры + visual_to_imu_offset_us`.
Согласование выполняется по действительной временной метке кадра;
интерполяция ИИМ допустима только внутри соседних измерений.
При больших пропусках или отсутствии ковариации коррекция
запрещается.

Файлы результата:

- `eskf_trajectory.csv`: относительные координаты, скорость,
  кватернион, смещения нуля, диагональные дисперсии и причины отказа
- `eskf_summary.json`: доля принятых визуальных измерений,
  распределение отказов, средняя NIS как диагностический показатель

При реальной статистической проверке оценивают распределение NIS,
покрытие доверительных интервалов, нормированные ошибки относительно
независимой эталонной траектории, влияние коррелированных ошибок
и повторяемость между разными полетами. Средняя NIS около двух сама
по себе не доказывает корректность модели, особенно после отбора
наблюдений порогом.

## Что остается за пределами данного PR

1. Оценка измерительных характеристик камеры, ИИМ и высотомера
   на стенде НИИВК, испытания на 20, 50, 100 м.
2. История номинальных состояний с корректировкой запаздывающих
   кадров и повторным прогнозом по исходным данным ИИМ.
3. Полная VIO по трёхмерным точкам изображения, калибровка
   смещения времени и взаимной установки камеры/ИИМ.
4. Отдельная картографическая коррекция накопленного дрейфа.
5. Проверка наблюдаемости, численной согласованности, отказов,
   вычислительной нагрузки и времени выполнения на бортовой ЭВМ.
6. Принятие и встраивание в PX4 только после подтвержденных
   результатов и отдельной программы стендовых и летных испытаний.

Для этого этапа наша ответственность ограничена ПО, математикой,
анализом логов и отчетами. НИИВК обеспечивает измерительное
оборудование, стенд, БВС и испытания.
