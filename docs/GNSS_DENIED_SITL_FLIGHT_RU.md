# Полет без ГНСС на оценках `ofnav`: PX4 SITL + Gazebo

## Что было

Модуль `ofnav` публиковал только диагностику. Ключ `-e` (передача
скорости в EKF2) отвергался: оптический поток дает лишь горизонтальную
скорость, а EKF2 принимает внешнюю скорость только в виде полного
трехмерного вектора. Подставлять вертикальную скорость «от себя»
правила проекта запрещают. Замкнутого контура управления на
собственных оценках `ofnav` не было.

## Что сделано

### Трехмерная скорость без придуманных величин

В ядре (`firmware/rtos_core`, тесты `test_ofnav`):

- `RangeRateEstimator` — вертикальная скорость NED по двум
  последовательным высотам над землей (дальномер с учетом наклона).
  Это измеренная величина, допускаемая только на интервале 20–300 мс.
  Действует допущение ровной земли между двумя отсчетами;
- `bodyVelocity3d` — вертикальная составляющая скорости в осях корпуса
  из vd и ориентации:
  vz = (vd − R₂₀·vx − R₂₁·vy) / R₂₂ с распространением дисперсии.
  Отказ при наклоне за пределами профиля.

### Передача в EKF2 — только сборки SITL

`ofnav start -e` публикует каждое принятое измерение потока как
`vehicle_visual_odometry`:

- скорость в осях корпуса FRD с дисперсиями модели;
- метка — середина интервала потока;
- положение и ориентация NaN.

EKF2 сливает ее при `EKF2_EV_CTRL=4` (3D-скорость). В полетных
сборках (NuttX) ключ `-e` по-прежнему **отвергается**.
`ofnav status` показывает `ev velocity to EKF2: published/skipped`.

### Найдено и исправлено: масштаб скорости 2/3

Сравнение опубликованной скорости с эталоном Gazebo показало, что
скорость `ofnav` равна 0,66–0,68 истинной. Причина — обработка
отсчетов-заглушек плагина потока: интервал заглушки добавлялся к
следующему отсчету. После исправления скорость совпадает с эталоном
(1,00–1,02), подробности — в `docs/GAZEBO_FAILURE_SCENARIOS_RU.md`.

### Сценарий

`tools/gz_no_gnss_flight.py`:

- `gz_x500_flow` без ГНСС (приемник в планере отключен),
  текстурированная сцена;
- параметры задаются при загрузке (`PX4_PARAM_*`):
  `EKF2_GPS_CTRL=0`, `EKF2_EV_CTRL=4`, `EKF2_HGT_REF=0`;
- взлет выполняется на штатном слиянии потока EKF2: ниже 0,2 м
  `ofnav` измерений не дает (диапазон профиля). Без горизонтальной
  коррекции аппарат при взлете в ALTCTL «уезжает» со скоростью до
  10 м/с — это было проверено;
- на высоте 2 м штатное слияние отключается (`EKF2_OF_CTRL=0`).
  Дальше **единственная** горизонтальная коррекция EKF2 — `ofnav`;
- эталон — `vehicle_local_position_groundtruth` (Gazebo), не оценка.

## Результат

| № | Проверка | Результат |
|---|---|---|
| 1 | EKF2 сливает только `ofnav` | PASS: `cs_ev_vel=True`, `cs_opt_flow=False`, `cs_gnss_pos=False`, `xy_valid=True`; 282 измерения передано, 154 пропущено (низкое качество, интервал) |
| 2 | POSCTL, ручки в нейтрали, 60 с | PASS: истинный уход 0,01 м, ошибка оценки 0,01 м |
| 3 | отклонение ручки 30 % на 5 с (до 0,81 м/с), затем отпускание | PASS: перемещение 2,93 м (истинное) / 2,97 м (оценка, +1,4 %), уход после остановки за 15 с — 0,01 м |
| — | отклонение 60 % (до 2,2 м/с — выше 1,5 м/с профиля) | справочно: 5,92 / 6,57 м (+11 %): часть измерений отклонена, EKF2 прогнозирует; аппарат останавливается (0,11 м) |
| 4 | AUTO.LAND на тех же оценках | PASS: посадка, разоружение |

До исправления масштаба то же отклонение ручки давало оценку на
33 % меньше истинной. При выходе за диапазон скорости после
остановки аппарат уходил на 37 м.

## Ограничения

- Только моделирование. В нем нет ветра, шумы ИИМ малы, и даже
  нескорректированная оценка удерживает зависание. Поэтому проверка
  удержания слабая; разделяющая проверка — маневр (п. 3).
- Взлет и последние 0,2 м посадки выполняются вне диапазона
  `ofnav`: при взлете работает штатный поток EKF2, при посадке
  EKF2 прогнозирует без коррекции.
- Вертикальная скорость по дальномеру предполагает ровную землю;
  на рельефе она ошибочна.
- Курс EKF2 — по магнитометру симулятора; курсовой ошибки `ofnav`
  не проверяется.
- Полетные сборки передачу в EKF2 не поддерживают, и это намеренно.

## Воспроизведение

```sh
make -C PX4-Autopilot px4_sitl_default   # с модулем ofnav, gz Harmonic
pip install pymavlink numpy pillow
python tools/gz_no_gnss_flight.py PX4-Autopilot --out build/gz_no_gnss
cat build/gz_no_gnss/gz_no_gnss_flight.json
```
